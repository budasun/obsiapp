# ObsiApp

Aplicación web de salud mental construida con React + TypeScript.

## 🚀 Demo en vivo
[https://obsiapp.vercel.app](https://obsiapp.vercel.app)

## ✨ Características
- Interfaz moderna y responsive
- Integración con servicios de backend (Supabase)
- Soporte multiidioma (i18n)
- Componentes reutilizables y tipados con TypeScript

## 🛠️ Tech Stack
- **Frontend:** React, TypeScript, Vite
- **Estilos:** CSS / Tailwind
- **Backend / Base de datos:** Supabase
- **Deploy:** Vercel

## 📦 Cómo correrlo localmente

```bash
git clone https://github.com/budasun/obsiapp.git
cd obsiapp
npm install
npm run dev
